## Proposed decisions

- 2026-10-12, T-098: the server image size limit (100 MB) applies to the unpacked file system measured with `docker export` of a created container, not to `docker image inspect` .Size, which reports unpacked size on the overlay2 store (Ubuntu 24.04 runners) but compressed content size on the containerd store (Ubuntu 26.04 runners, Docker Desktop). server.yml stays on `ubuntu-latest`; `ubuntu-24.04` is the fallback only if the first real Ubuntu 26 run fails. Reason: run 38296076877 on ubuntu-26.04 passed every step with identical export sizes (11.9 MB amd64, 11.2 MB arm64).
- 2026-10-12, T-098: CI checks `/app/server --healthcheck` inside the running image on both platforms (exit 0 up, 1 nothing listening, 64 bad argument) and `docker compose config -q` with deploy/.env.example, plus a no-values run that must fail.
