**How to update goldens (for docs/decisions.md).** From the repository root, on a pushed branch:

```
gh workflow run app.yml --ref <branch> -f update_goldens=true
gh run list --workflow app.yml --branch <branch> --event workflow_dispatch --limit 1
gh run download <run-id> --name goldens --dir app/test/goldens
git add app/test/goldens/*.png
git commit -m "T-0xx: update goldens from app.yml run <run-id>"
```

Delete the old PNG first when a golden is renamed or removed, because the download only adds and overwrites files.

**What changed**
- `.github/workflows/app.yml`
  - New `workflow_dispatch` input `update_goldens` (boolean, default false). When it is true, only the new `goldens-update` job runs. It uses ubuntu-24.04, the same as the checks job, and installs `env.FLUTTER_VERSION` with `tool/ci/install_flutter.sh`. It runs `flutter test --update-goldens test/goldens` and uploads `app/test/goldens/**/*.png` as the artifact `goldens` (14 days, and the step fails if there are no PNGs).
  - The checks, codegen, android, and iOS jobs are skipped on that run, so a golden render spends no macOS minutes. The concurrency group gets a `-goldens` suffix so a render run does not cancel the branch's push run.
  - The checks job's Test step already runs the golden comparisons. If the job fails and failure PNGs exist, a new step uploads `app/test/**/failures/*.png` as the artifact `golden-failures`.
