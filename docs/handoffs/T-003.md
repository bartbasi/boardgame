## Proposed decisions

For the orchestrator to record if accepted:

1. Top-level destinations: Scan, Search, Collection, Settings, in that order. T-012's assumption of three destinations changes to four.
2. Navigation: NavigationBar under 600 dp wide; NavigationRail from 600 dp. Two-pane on Search, Collection, and candidates from 840 dp wide and 600 dp tall.
3. Seed color `0xFF1F6B5C`, Material 3, dynamic color off.
4. Shared test definitions: keep compact 390 x 844, medium 744 x 1133, expanded 1280 x 800, text scale 2.0. Add a fourth size `landscape` 844 x 390 dp for the goldens that name it. Add the golden state suffix `text200` (for example `scanner_denied_text200_light_compact.png`) for goldens rendered at text scale 2.0. The naming pattern stays `<screen>_<state>_<theme>_<size>.png`; screen names use underscores and the state may contain a suffix after a second underscore.
5. Autosave on the edit screen. Add, move, remove, import, and restore use Undo instead of confirmation dialogs.
6. Time phrases come from one formatter ("5 hours ago"); price data older than 48 hours is stale; fewer than 3 listings gets a "few listings" note (the PRD's assumptions, used as is).

## Round 2
### Author notes (ux-designer)

Applied the 11 changes from docs/handoffs/T-001.md "Round 2" to docs/ux/. Facts used: EBAY-20, EBAY-92, EBAY-93, EBAY-100, BGG-40, BGG-41, BGG-42, APPLE-01 to APPLE-03, GPLAY-03, api-research section 4.

What changed:

1. **Age limits.** The 48-hour rule is gone everywhere (components.md, copy.md, collection.md, game-detail.md, listings.md, flows). Price summaries get a stale marker after 6 hours and are hidden after 24 hours. Listings are never shown older than 6 hours, so listings.md has no stale state, `listings.staleNote` and `listings_stale_light_compact.png` are removed, and offline shows `listings.offlineTitle` and `listings.offlineBody` ("Listings and prices need a connection.") with no rows.
2. **Listing row age.** New `listings.rowAge` ("Checked 2 hours ago") on every row; `listings.rowLabel` includes it.
3. **Too old price.** New state "Price too old" (`price.tooOldTitle`, `price.tooOldBody`) on game detail. Offline price is valid only within 24 hours. Collection rows older than 24 hours read `collection.rowPriceMissing` ("No current price data") and the total leaves them out (`collection.totalTooOld`, `collection.totalCoverage` now says "current price data"). Goldens: `game_detail_price_toold_light_compact.png`, `collection_owned_pricesmixed_light_compact.png` (replaces the old stale and none variants).
4. **History unavailable.** price-history.md has a "History unavailable" state (`history.unavailableTitle`, `history.unavailableBody`), golden `price_history_unavailable_light_compact.png`. Game detail hides `price.seeHistory` when history is off.
5. **Disclosure.** Placeholder wording is now "Paid link: as an eBay Partner, we may be compensated if you make a purchase." (`common.disclosureShort`, `listings.disclosure`), marked PLACEHOLDER pending Q25. Settings heading is "Paid link disclosure". Listings: the disclosure is the first element of a pinned top region (left column in landscape and expanded), so it is on screen without scrolling at all sizes including landscape and text200; goldens `listings_success_light_landscape.png`, `listings_success_text200_light_compact.png`, and `listings_success_text200_dark_landscape.png` prove it. Game detail: the disclosure sits directly above "See eBay listings" inside the price card. Internal technical mentions of "affiliate URL" remain only in non-user-facing notes.
6. **BGG credit and logo.** BGG-40 and BGG-41 settle it, so the BGG PLACEHOLDER strings are replaced by `common.bggCredit` and `common.bggLogoLabel`. BggAttribution now appears on game detail, search, lookup-result (states that show games), collection, collection item edit, listings, price history, and Settings About. Still open: the official logo file and size (T-087, T-091); a placeholder box is drawn until then. Removed keys: `common.poweredByBgg`, `common.poweredByBggLabel`, `gameDetail.openOnBgg`, `search.resultsFooterBgg`, `settings.bggAttribution` (now `settings.bggCredit`).
7. **No cover images.** components.md defines a no-image mode (one `showCoverImages` setting, default per Q5): rows lose the thumbnail, headers lose the cover. Every spec states it; golden `game_detail_noimages_light_compact.png`; widget tests for the rest.
8. **No sold state.** Removed `price.badgeSold`, `price.medianSold`, `price.sampleSold`, `price.soldDisabledNote`, the sold badge variant, the sold card, the sold history row, and the sold flow row.
9. **Camera text.** `scanner.iosUsageDescription` is now "Scan a game's barcode to look it up. If you add photos of your games, they stay on this device." (api-research section 4). Photo library access still needs its own purpose string when T-041 is built.
10. **Privacy policy.** settings.md has a `settings.privacyPolicy` row as the first row of About, opening the hosted policy. The row is final copy; only the URL is a placeholder (T-078).
11. **Goldens trimmed** with the T-001 rule (cap 8 per screen per milestone, light compact per distinct state, one dark success, one widest layout, one text200, one loading, rest by widget tests).
